# Product Backlog - Sistema de Biblioteca

O Product Backlog contém todas as funcionalidades e requisitos desejados para o sistema, priorizados com base no valor entregue ao negócio.

## Funcionalidades (Épicos e Histórias de Usuário)

| ID | Funcionalidade | Prioridade | Status |
|---|---|---|---|
| 01 | Cadastrar novo livro no acervo | ALTA | Concluído (Sprint 1) |
| 02 | Listar todos os livros disponíveis | ALTA | Concluído (Sprint 1) |
| 03 | Registrar novo empréstimo de livro | ALTA | Concluído (Sprint 1) |
| 04 | Listar histórico de empréstimos | ALTA | Concluído (Sprint 1) |
| 05 | Registrar devolução de livro | MÉDIA | A Fazer |
| 06 | Cadastrar novo usuário (leitor) | MÉDIA | A Fazer |
| 07 | Autenticação e Login de usuários | MÉDIA | A Fazer |
| 08 | Notificar usuário sobre atraso de devolução | BAIXA | A Fazer |
| 09 | Relatório de livros mais emprestados | BAIXA | A Fazer |
| 10 | Avaliação de livros pelos usuários | BAIXA | A Fazer |

*Nota: A prioridade foi definida pela equipe considerando os requisitos essenciais para o MVP (Minimum Viable Product).*
